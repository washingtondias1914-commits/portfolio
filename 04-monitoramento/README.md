# 🖥️ Projeto 04 - Infraestrutura com Monitoramento

## 📋 Descrição

Stack completa de monitoramento e logging para infraestrutura corporativa usando Zabbix, Prometheus, Grafana e ELK Stack.

## 📂 Estrutura

```
04-monitoramento/
├── README.md
├── zabbix/
│   └── docker-compose.yml
├── grafana/
│   └── dashboards/
└── evidencias/
    ├── grafana-dashboard.svg
    ├── zabbix-dashboard.svg
    └── kibana-dashboard.svg
```

## 🚀 Como Usar (resumo)

- Requisitos: Docker, Docker Compose
- `docker-compose up -d` nas stacks (zabbix, grafana, elk)
